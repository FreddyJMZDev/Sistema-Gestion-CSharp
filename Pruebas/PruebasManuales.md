# Pruebas del Sistema de Gestión

## Objetivo
Comprobar el funcionamiento de las operaciones CRUD y el almacenamiento local de registros.

## Casos de prueba

- [ ] Agregar un registro correctamente.
- [ ] Intentar agregar un registro sin nombre.
- [ ] Intentar agregar un registro sin correo.
- [ ] Mostrar todos los registros.
- [ ] Buscar un registro existente.
- [ ] Buscar un registro inexistente.
- [ ] Editar un registro existente.
- [ ] Intentar editar un ID inexistente.
- [ ] Eliminar un registro existente.
- [ ] Cancelar una eliminación.
- [ ] Cerrar y volver a abrir la aplicación.
- [ ] Comprobar que los registros se conservan en JSON.

## Resultado
Pendiente de ejecución y verificación.

## Observaciones
Las pruebas se realizarán manualmente desde la aplicación de consola desarrollada en C#.
