# Sistema de Gestión de Registros - C#

Aplicación de consola desarrollada en **C# y .NET Framework 4.8**, aplicando principios de Programación Orientada a Objetos (POO) y una estructura modular para la administración de registros.

## Características

- Crear registros con identificadores automáticos.
- Consultar todos los registros almacenados.
- Buscar registros por nombre.
- Editar registros existentes.
- Eliminar registros con confirmación.
- Validar nombres y correos electrónicos.
- Guardar y recuperar información mediante archivos JSON.

## Tecnologías utilizadas

- **Lenguaje:** C#
- **Framework:** .NET Framework 4.8
- **IDE:** Visual Studio
- **Persistencia:** JSON
- **Paradigma:** Programación Orientada a Objetos

## Instalación y ejecución

1. Clonar o descargar el repositorio.
2. Abrir `SistemaGestion.sln` en Visual Studio.
3. Tener instalado el paquete de desarrollo de .NET Framework 4.8.
4. Compilar la solución.
5. Ejecutar con `Ctrl + F5`.
